# Harmony Laptop Ubuntu Install Script
Use the `Install.sh` bash script or `user-data` autoinstall file on a Ubuntu 26.04.1 Laptop or Desktop

<small>`user-data` is fs broken right now, ill fit it later</small>

Installs
* VLC
* Audacity
* GIMP
* Canva (Shortcut)
* SoundShow

Configures
* Dark Mode
* Time AM/PM
* Dock Autohide
* Dock Placement (Bottom)
* Configues Pins
* Network (user-data only)
