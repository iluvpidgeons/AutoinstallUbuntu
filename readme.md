# Harmony Laptop Ubuntu Install Script
Use the `Install.sh` bash script or `user-data` autoinstall file on a Ubuntu Laptop or Desktop

Installs
* VLC
* Audacity
* GIMP
* Canva (Shortcut)
* SoundShow

Configures
* Dark Mode
* Time AM/PM
* Dock Autohide
* Dock Placement (Bottom)
* Configues Pins
* Network (user-data only)
